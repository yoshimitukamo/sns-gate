# SNS Gate

X (Twitter) と Facebook を「惰性で開く」のを防ぐ Chrome 拡張。

サイトを開こうとすると「なぜ開きますか？」と理由を聞かれます。理由が見つからなければ自然と閉じられます。意図的に開いた場合だけ通過できます。

## 機能

- X (Twitter) / Facebook へのアクセスをゲートでブロック
- 「やっぱり開かない」を選ぶと Google トップへ（SNS サーバーにリクエストは届かない）
- 訪問回数・滞在時間・理由をローカル保存して可視化
- 滞在時間はタブがアクティブ・フォーカスされている時間から推定します（バックグラウンドタブの時間は含みません）

## インストール

1. このリポジトリをクローン or ZIP でダウンロード
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ `sns-gate/` フォルダを選択

## 使い方

X や Facebook を開こうとすると自動でゲートが表示されます。理由を選んで「この理由で開く」をクリックすると通過。「やっぱり開かない」を押すと Google トップへ移動します。

拡張機能アイコンをクリックすると今日・今週・今月の利用状況が見られます。

## データについて

すべてのデータはブラウザのローカルストレージにのみ保存されます。外部サーバーへの送信は一切ありません。
